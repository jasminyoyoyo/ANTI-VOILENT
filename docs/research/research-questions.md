# Research Questions

## Core Question

Why would someone open Beacon, and what do they need within the first 10 seconds?

## User Motivation

1. What situation makes someone search for help?
2. Are they looking for emotional support, practical steps, emergency help, or confirmation?
3. Are they acting for themselves or someone else?
4. What language would they use to describe the problem?
5. What words would make them leave immediately?

## First-Screen Needs

1. What should the first screen ask?
2. Should the homepage be organized by features or situations?
3. Which path should be most prominent?
4. Should "Call 000" be visible immediately?
5. How visible should Quick Exit be?
6. How visible should Disguise Mode be?

## Trust

1. Would users trust AI in this context?
2. What should AI never claim to do?
3. What makes the product feel safe?
4. What makes it feel fake, risky, or childish?
5. Should the product show official services before AI-generated content?

## Privacy And Device Safety

1. Are users worried someone will check their phone?
2. Are they worried about location tracking?
3. Would they save notes on the device?
4. Would they use a disguised mode?
5. Would a weather disguise be believable?
6. What is the safest way to show instructions?

## Feature Value

For each feature, ask:

1. What problem does this solve?
2. When would someone use it?
3. What output does it create?
4. Is it better than existing alternatives?
5. Could it increase risk?
6. Should it be first-screen, secondary, hidden, or removed?

Features to evaluate:

- AI chat
- risk check
- safety plan
- resources
- quick exit
- disguise mode
- safe notes
- voice mode
- safe word message
- evidence timeline
- phone safety check
- help someone else

## Success Metrics

1. Can users choose a path in under 10 seconds?
2. Can users explain what Beacon is after seeing the homepage?
3. Can users find emergency help in one click?
4. Can users find phone safety guidance quickly?
5. Can users find a non-emergency next step without reading a long page?
6. Do users understand that AI is not emergency support?
