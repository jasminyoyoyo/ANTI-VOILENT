# “为什么不离开？”可能问错了问题

## 1. 议题简要摘要

社会上常把“离开暴力关系”描述成一个简单的个人选择：既然正在遭受伤害，为什么不马上离开？

这个议题想研究的不是受害者“为什么作出错误选择”，而是：**当人身安全、经济控制、住房、子女、情感关系和报复风险同时存在时，一个人实际拥有多少离开的条件？**

数据故事可以围绕三层问题展开：

1. **离开是否是一条直线？**  
   有些女性会暂时离开、返回关系、再次离开。返回不等于暴力不存在，也不等于受害者接受暴力。

2. **是什么让离开变得困难？**  
   ABS PSS 记录的原因包括想修复关系、伴侣承诺停止暴力、仍然爱着伴侣、没有经济支持、无处可去，以及担心自己或孩子的安全。

3. **离开以后，社会支持系统能否接住她？**  
   AIHW 的 Specialist Homelessness Services（SHS）数据可以呈现：有多少经历家庭暴力的人需要住房和支持、多少人在求助时已经无家可归，以及住宿需求是否得到满足。

建议将核心结论写成：

> “离开”不是一个瞬间的决定，而是一段需要安全、住房、经济资源和持续支持的过程。与其追问“她为什么不走”，不如追问“她走了以后，能去哪里，谁能保证她和孩子的安全？”

### 这项分析不能证明什么

- 它不能证明每位受害者不离开的具体原因。
- PSS 是抽样调查估计；警方记录和 SHS 数据是行政服务记录，三者不是同一种统计。
- SHS 客户人数不是澳大利亚全部 FDV 受害者人数，也不是暴力事件发生率。
- 不同年份的数据可以共同描述结构性问题，但不能假装来自同一时期或同一批人。
- 这些数据主要显示群体层面的模式，不能用来评价某一位受害者的决定。

### 2.3 已确认的重要数值

ABS Table 18.1 显示：

- 约1,364,700名女性曾在共同生活期间经历前任伴侣暴力。
- 其中约583,800人曾暂时分开，占42.8%。
- 在曾暂时分开的女性中，57.4%表示曾因“想尝试解决问题”返回。
- 50.7%表示伴侣曾承诺停止袭击或威胁。
- 44.7%表示仍然爱着伴侣。
- 21.5%表示没有钱或经济支持。
- 19.4%表示无处可去。
- 13.7%表示担心孩子的安全或福祉。
- 8.5%表示担心自身安全或福祉。

这些返回原因允许多选，因此比例相加会超过100%。

AIHW 2024–25 SHS 数据显示：

- 约117,000名经历过FDV的客户获得SHS协助，占全部SHS客户约40%。
- 约46,800人在首次求助时已经处于无家可归状态。
- 约51,700人需要短期或紧急住宿，约35,600人获得了该项服务。

最后一组“需要”和“获得”可以用来展示服务缺口，但不能简单断言两者之差全部等于“被拒绝人数”；一个人可能被转介、需求状态可能变化，最终口径要按AIHW技术说明核对。

## 3. 建议展示的图表：按照读者的问题推进

整套故事先回答“有多少人”，再进入“她有没有尝试离开”，最后逐一展示使离开变得困难的现实条件。

### 图1：有多少女性经历过伴侣暴力？

**要回答的问题：** 这是不是少数人的个别遭遇？

**建议形式：** 一个大数字加100人图，或者“全部成年女性—经历过伴侣暴力”的分段条形图。

**大致内容：**

- 澳大利亚约990万名成年女性；
- 自15岁以来，约170万名女性经历过同居伴侣暴力；
- 占成年女性约17%；
- 其中约150万名女性经历过前任伴侣暴力。

**数据源：** ABS《Partner violence, 2021–22》，Partner violence and abuse prevalence（Table 1）以及网页 Violence 章节。

**推荐标题：**  
“在澳大利亚，大约每六名成年女性中就有一人经历过伴侣暴力”

**口径提醒：** 这里的“暴力”指实际发生、企图实施或面对面威胁实施身体或性侵害；它不自动包含所有情感虐待和经济虐待。约170万是PSS抽样调查的人口估计，不是警方记录数。

### 图2：有多少人曾经试过离开？

**要回答的问题：** 她们是否真的从未尝试离开？

**建议形式：** 从基数展开的分段条形图或简单漏斗。

**大致内容：**

- 约1,364,700名女性曾在共同生活期间经历前任伴侣暴力；
- 其中约583,800人曾与伴侣暂时分开，占42.8%；
- 约218,900人暂时分开一次；
- 约357,900人暂时分开多次。

**数据源：** ABS Partner violence 2021–22，Table 18.1；RSE 来自 Table 18.2。

**推荐标题：**  
“不是没有试过：约58万名女性曾暂时离开”

**口径提醒：** 42.8%的分母是“曾在共同生活期间经历前任伴侣暴力的女性”，不是全部成年女性。由于ABS对单元格作了随机调整，分项与合计可能出现轻微差异。

### 图3：有多少人离开以后又回到关系中？

**要回答的问题：** 暂时离开是否意味着关系已经永久结束？

**建议形式：** 两阶段流程图。

**大致内容：**

1. 约583,800名女性曾暂时与使用暴力的前任伴侣分开，后来回到关系中；
2. 其中约369,400人在至少一次暂时分开期间由自己搬离住所，占63.3%。

第二个数字可以帮助读者理解：一部分女性不只是情感上提出分开，而是真的搬离过住所，之后仍然回到了关系中。

**数据源：** ABS Table 18.1；RSE 来自 Table 18.2。

**推荐标题：**  
“有人已经走出家门，却仍不得不回去”

**重要口径：** ABS 的“暂时分开”本身就意味着后来恢复过关系，所以“曾试过离开”和“离开后返回”主要是同一批约583,800名女性，不能把两个数字相加。约369,400是其中曾由自己搬离住所的子群体。

### 图5：有孩子时，离开是谁的安全问题？

**对应担忧：**  
“如果我走了，小孩怎么办？孩子会不会继续受到伤害？”

**建议形式：** 上下两个小图或一个主图加事实卡。

**大致内容：**

“她考虑的，可能不只是自己的安全”

## 4. 一个图表能否混合多种数据？

可以，但“混合数据”分为两种：

### 4.1 可以安全混合的情况

同一来源、同一人群、同一时间范围、同一单位的数据通常可以进入同一坐标系。例如：

- Table 18.1 中不同返回原因的比例；
- AIHW 中各州“需要紧急住宿”和“获得紧急住宿”的人数；
- 同一ABS表中不同家庭结构的两年经历比例。

### 4.2 适合放在同一张信息图、但不应画在同一坐标轴的情况

ABS PSS 与 AIHW SHS 可以共同服务同一个故事，但它们的统计对象不同：

| 数据 | 统计对象 | 指标性质 |
|---|---|---|
| ABS PSS | 抽样调查中的澳大利亚成年人口 | 经历比例和人口估计 |
| AIHW SHS | 接触专业无家可归服务的客户 | 服务使用与需求记录 |
| 警方 Recorded Crime | 被警方记录的受害者或案件 | 行政记录，受报案和记录制度影响 |

因此，建议用**多面板组合图**：每个面板保留自己的单位、年份、分母和来源，再由同一个标题或叙事连接。不要使用双轴强行把“调查比例”和“服务人数”画成两条看似可比较的线。

### 4.3 不建议直接混合的情况

- 将2021–22 PSS调查估计和2024–25 SHS客户人数相加；
- 用SHS客户人数除以PSS受害者估计，声称这是“求助率”；
- 将警方记录数与PSS人数之差称为“未报警人数”，除非年份、地区、人群、事件定义和计数单位全部对齐；
- 将不同分母的百分比放在同一堆叠条中，使其看起来合计为100%；
- 把“需要服务”和“获得服务”的差值直接称为“遭拒绝”，而不核对转介和未满足需求定义。

### 4.4 推荐的混合方式

最适合本议题的是：

1. **主图使用单一来源**：例如返回原因条形图只使用ABS Table 18.1。
2. **旁边增加来源独立的事实卡**：例如AIHW的117,000名FDV客户。
3. **每个数字旁写清四件事**：年份、人群、单位、来源。
4. **图下注明不可直接比较的原因**。
5. 如果做Instagram轮播，每页最好只承担一个问题；最后一页再把不同来源组成证据地图。
