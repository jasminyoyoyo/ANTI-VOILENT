# Beacon

Beacon is a React + Vite demo for a trauma-informed domestic and family violence support experience focused on Australia.

## What this demo includes

- discreet AI chat support
- local resource discovery
- personalised safety planning
- quick exit and disguise mode

## Tech stack

- React 19
- TypeScript
- Vite
- Xiaomi MiMo API (OpenAI-compatible endpoint)

## Run locally

Prerequisites:

- Node.js 18+

Steps:

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local`
3. Choose a provider in `.env.local`:
   `VITE_AI_PROVIDER=gemini`
   `VITE_GEMINI_API_KEY=...`
   or
   `VITE_AI_PROVIDER=mimo`
   `VITE_MIMO_API_KEY=...`
4. Start the dev server:
   `npm run dev`

## Build

`npm run build`

## Notes

- This is a demonstration project, not an emergency service.
- If someone is in immediate danger in Australia, they should call `000`.
- Resource suggestions generated by AI should always be verified before use.
